# book-figure-bw：书稿图片黑白优化

将已有彩色书稿图、技术路线图和流程示意图重建为适合黑白印刷的SVG与可编辑PowerPoint。先生成无文字底图，再按原坐标回填文字；默认保留原文，仅按明确要求精简。

这是给Codex使用的工作流技能，不是独立运行的图片转换软件。

GitHub仓库：[6iu1ang/book-figure-bw](https://github.com/6iu1ang/book-figure-bw)。技能入口：`skills/book-figure-bw/SKILL.md`。

## 工作流程

保存原图和任务约定 → OCR测量与内容核对 → 黑白图形分离和矢量化 → 保存无字底图 → 按原坐标回填 → 文件和版面检查 → 交付与进度记录。

保留比例、分区、箭头方向、对象对应关系，以及标准编号、年份、案例名称、数值和关键条件。SVG和PPT从同一坐标体系构建；不同任务可分别选择保留原文、局部精简或全文精简。

## 依赖与环境

| 依赖 | 用途与安装方式 |
|---|---|
| Codex及可用图像生成/编辑能力 | 执行重建与素材分离；调用能力取决于接收者环境 |
| [image-to-editable-ppt](https://github.com/ningzimu/image-to-editable-ppt-skill) | 核心对象重建和校验，安装仓库中的 `skills/image-to-editable-ppt` |
| `editppt` | 按上游技能说明安装并检查，不随本包附带运行环境 |
| Python及矢量化工具（例如vtracer） | 将经过核对的线描素材转换为SVG；执行时检查依赖 |
| PaddleOCR配置 | 提高文字及坐标识别质量，接收者自行配置；按上游技能允许的方式处理未配置情况 |
| Microsoft PowerPoint | 用于实际打开、导入SVG及导出预览；缺少时不能声称已通过PowerPoint检查 |

本分享包仅包含本技能及说明，不打包上述第三方软件、账户凭据、OCR令牌、作者书稿或图片。使用OCR和图像工具时，按接收者自己的配置和任务处理限制执行。

## 可直接复制的使用提示词

先附上原图，再复制相应提示词。将图号、目录、待精简区域替换为实际值；未提供插图宽度时不必填写。

### 1. 保留原文，优化黑白打印

```text
请使用 $book-figure-bw 处理这张彩色书稿图片，优化黑白打印效果。
图号：图X-X
保存到当前项目下“图X-X_黑白版”。
先生成无文字SVG，再按原坐标回填文字。
文字保留原文；复杂插画允许简化为黑白线描。
保持原图比例、分区、箭头方向和逻辑关系。
交付无文字SVG、文字回填SVG、可编辑PPT、黑白预览、文字坐标和检查报告。
保留输入原图，采用新版本保存，不直接修改Word书稿。
```

### 2. 优化黑白打印，同时精简全文

```text
请使用 $book-figure-bw 优化这张书稿图片，保存到“图X-X_黑白精简版”。
先制作无文字SVG底图，再按原坐标回填精简文字，保持原有分区和逻辑关系。
合并重复表述、压缩冗长说明，保留所有标准编号、年份、案例名称、数值、
公式、单位、专业含义和关键限制条件；提供原文与精简文字对照。
复杂插画允许简化为黑白线描，主要图形身份、箭头方向和关系保持一致。
交付两份SVG、可编辑PPT、预览、坐标、修改对照与检查报告。
保留原图和旧成果，不直接修改Word书稿。
```

### 3. 只精简指定区域

```text
请使用 $book-figure-bw 处理这张图片，保存到“图X-X_黑白版”。
仅精简【上方说明区】的文字，其他区域保留原文；列出该区域的修改对照。
改为白底、黑线和浅灰分区，保留原图比例、分区与箭头关系。
先输出无文字SVG，再按原坐标回填；交付可编辑PPT、完整SVG、预览和检查报告。
复杂图形仅改为黑白样式，暂不额外删减细节。
```

### 4. 批量处理多张图片

```text
请使用 $book-figure-bw 按以下对应关系处理所附图片：
第1张：图X-1；第2张：图X-2；第3张：图X-3。
每张图分别保存到同名“_黑白版”文件夹，分别建立进度记录和检查报告。
所有文字保留原文，复杂插画允许简化为黑白线描。
每张先生成无文字SVG，再按各自原坐标回填，保留比例、分区和逻辑关系。
每图交付两份SVG、可编辑PPT、黑白预览和文字坐标；最后列出各图完成状态。
若一张图有不可辨的关键文字，具体记录该图待核内容，不猜写为已通过。
```

### 5. 中断后继续未完成任务

```text
请使用 $book-figure-bw 继续“图X-X_黑白版”的未完成工作。
先读取进度说明、任务约定、已有构建目录及运行状态，从实际文件恢复。
保留已核对通过的文字和素材，仅重做未完成或本次修改影响的内容。
完成最终文件打开、文字溢出、图文碰撞、纯矢量和黑白效果检查，
更新进度和检查报告后交付。保留旧版本，不覆盖输入原图。
```

如果已知最终插图宽度，可在上述提示词末尾加：“最终书稿插图宽度为×厘米，请按该尺寸检查文字和线条可读性。”软件检查与纸张试印分别记录。

## 成果与检查

默认成果：无文字SVG、文字回填SVG、可编辑PPTX、灰度预览、文字坐标、交付检查、交付说明和进度记录。原图不覆盖，更新采用新版本。

普通文字为SVG文本和PPT原生文本框；框线及箭头是独立结构对象；复杂插图为独立SVG对象，可进一步转换为形状。公式的编辑方式单列说明。

检查包括内容完整性、原坐标对应、纯矢量、图标完整性、文字溢出与碰撞、黑白分类辨识、最终文件实际打开及指定尺寸可读性。软件预览和纸张试印分别记录，不将未执行检查记为通过。

详细任务约定见 [task-contract.md](https://github.com/6iu1ang/book-figure-bw/blob/main/skills/book-figure-bw/references/task-contract.md)。
