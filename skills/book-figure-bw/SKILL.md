# 书稿图片黑白优化

将既有书稿图片重建为适合黑白印刷、可追踪修改和继续编辑的图。默认交付无文字SVG、文字回填SVG、可编辑PPTX、预览、文字坐标和检查报告。

## 任务边界与依赖

- 默认保留原文；只有用户明确要求时才精简指定区域。前一张图的精简授权不自动延伸到下一张图。
- 保持原图比例、分区、对象位置、箭头方向和层级。颜色转换为黑白/灰度是本任务的修改范围；复杂图形的进一步简化依据当前用户要求，保留原对象身份与关键语义。
- 数值、年份、标准编号、公式、案例名称、图例对应和地理关系不得被图像生成或文案压缩改写。不从示意图反推未知数据。
- 仅修改图片交付文件；插入Word、替换书稿原图、批量重处理旧成果或上传发布需要相应任务授权。
- 本技能是 `image-to-editable-ppt` 的黑白印刷任务扩展。开始重建前在当前环境的技能目录中定位并读取其 `SKILL.md`，按阶段读取 `cli-helper.md`、`manifest-schema.md`、`page-decision-tree.md` 和页工作提示。缺失时，从 `https://github.com/ningzimu/image-to-editable-ppt-skill` 安装 `skills/image-to-editable-ppt`，按其说明检查 `editppt` 运行工具，不依赖作者电脑上的路径。
- 需要图像分离/编辑时使用可用的内置图像工具，并读取 `imagegen` 技能。按原技能的对象来源与后端规则执行；不要把整张原图塞进PPT，或用手工拼凑图标代替要求的素材分离。
- 原技能要求保留颜色/样式而用户明确要求黑白或简化时，以用户的修改范围为准并记录变化；不免除对象分离与来源记录。
- OCR和图像工具的本地配置可复用。已有识别方式选择或处理授权时不重复确认；遵守本地处理/保密限制，不展示或写入项目中的令牌。

新图或恢复任务时读取 [references/task-contract.md](references/task-contract.md)，使用其中的默认参数、调用模板、命名和验收标准。

## 执行流程

### 1. 保存原图与任务约定

确定输入、图号/名称、目录、文字模式、简化范围、插图宽度（若已提供）和版本。可选参数使用参考文件默认值，缺少原图或关键内容不可辨时请求必要信息。保留原图不覆盖，为本图建立独立构建与交付目录，保存图像宽高、内容清单和任务约定。

### 2. 测量文字并核对内容

用 `editppt prepare` 准备输入；单页按原技能生成页提示并 `run dispatch --local` 领取，多页按原技能页工作调度执行。先核查背景、前景素材和原生结构边界，再重建。

使用OCR文字、边界框、字号测量及分组，对照原图补核；漏识别不等于可删除。保存原文与原始锚点。影响含义的不可辨文字不能猜写后宣布通过。需要精简时建立“原文→回填文→修改理由”对照，保留专业信息与逻辑关系。

### 3. 制作无文字黑白底图

采用白底、黑线和有节制的浅灰分区；色彩分类改用编号、边框、虚实线或纹理。保留有意义的连接和边界，降低装饰背景对正文的干扰。

框、线、箭头和容器重建为原生结构对象；复杂图标、照片和插画按原技能分离，按允许范围转为黑白线描。生成提示以原图为严格参考，列出对象清单、不得改变的语义，不含回填文字。核对素材后进行背景清理、拆分和矢量化。

矢量化后检查细线、空洞、轮廓和箭头；降低细节不能破坏科学含义。保存并检查无文字SVG后才回填。无文字稿不得残留字迹或伪文字。

### 4. 按同一坐标体系回填

以源像素 `0,0,W,H` 为共同基准，沿用原锚点、分区和对应关系。SVG和PPT从同一对象清单/manifest构建，避免分别排版造成漂移。

普通文字使用真实SVG文本和原生PPT文本框；公式单独转录并按原技能处理，不使用生成图片中的公式。使用可用中文字体，同层级字号一致。可为消除溢出调整框大小、分行或同层级字号，记录修正；未经要求不重组版面。精简时利用腾出的空间改善可读性并核对关键内容。

### 5. 验证与修正

完成原技能结构校验，并实际用PowerPoint打开/导出预览（可用时），检查SVG导入和渲染。按参考文件逐项核对文字、图形、坐标、灰度和编辑能力。

若给定书稿插图宽度，在该尺寸检查字与线条；未知则记录“最终尺寸未指定”。灰度/对比度变化后，分类仍应有编号或轮廓可辨，不以灰度差为唯一线索。

`page validate → run record → run finalize` 的状态由CLI维护，不手写状态JSON。最终组装可能重建PPT，对最终交付文件再做实际打开检查；中间文件通过不代表最终文件通过。软件预览不能记为纸张试印。

### 6. 交付与续做

保存约定成果，报告通过项、待核项和文件链接。独立SVG图标可进一步“转换为形状”，不等于已经拆成原生路径；说明真实编辑范围。

分阶段更新进度，记录完成项、下一步和依赖文件。恢复时读取任务约定、进度、素材和 `editppt run next`，只处理未完成或本次修改影响的部分。反复失败先修复根因再重试，不凭空标记完成。
