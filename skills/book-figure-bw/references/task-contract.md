# 任务约定、调用模板与验收

## 调用模板

```text
请使用 $book-figure-bw 处理这张书稿图片。
图号/名称：图X-X／图片名称
保存目录：当前项目下的“图X-X_黑白版”
文字：保留原文（或：仅精简上方说明／按原逻辑精简全文）
图形：保留主要图形；复杂插画允许简化为黑白线描
布局：保持原图比例、分区和原坐标
最终插图宽度：如已知，填写厘米数；未知可省略
交付：无文字SVG、文字回填SVG、可编辑PPT、预览、坐标与检查报告
```

不必填写所有参数。默认保留原文、图形身份和语义、源坐标；当前项目保存，新版本不覆盖旧交付。图号未知按名称建目录。批量任务的图号与源图一一对应，每图可分别指定文字模式，不能从一图要求推断全批次都应精简。

## 文件约定

交付目录为 `<图号或名称>_黑白版/` 或用户指定目录；已有同名文件则递增版本。

| 文件 | 用途 |
|---|---|
| `01_无文字_v1.svg` | 无文字纯矢量底稿 |
| `02_文字回填_v1.svg` | 普通文字为可编辑text元素的完整矢量稿 |
| `03_可编辑_v1.pptx` | 文字、结构对象、独立矢量插图可分别编辑 |
| `04_黑白预览_v1.png` | 记录PowerPoint或其他实际渲染来源 |
| `05_文字坐标_v1.json` | 原文、回填文、原始及最终坐标、字体和修改记录 |
| `06_交付检查_v1.json` | 实际检查结果及未完成项 |
| `07_交付说明_v1.md` | 使用方式、编辑范围与已知限制 |
| `进度说明.md` | 完成项、当前文件、待办与恢复入口 |

构建目录为独立 `.build_<图号或名称>_v1/`，保留原图、任务约定、OCR、manifest、素材来源、构建源和验证证据。遵循editppt生成的目录，不手写运行状态。无文字PPT、无文字预览、独立精简对照可按任务增加。

## 坐标与文案记录

原点为源图左上角，x向右、y向下；边界框 `[x,y,width,height]` 单位为源像素，页面保持 `W:H`。

每条文字记录稳定 `id`、所属分区、`original_text`、`refilled_text`、`source_box_px`、`final_box_px`、对齐方式、最终字体/字号和修改原因。区分OCR测量与人工补核。原框与最终框独立保存，不能把调整后坐标当原坐标。

未调整锚点直接复用原值；误识别边界、漏字、分行和字体差异导致调整时，记录依据和位置变化。大幅重排先核对是否在用户要求范围内。字号单位明确为pt或源像素，不与坐标混用。标准编号、年份、单位、公式、案例名称逐字核对，不能为缩短文字删除关键限制条件。

## 验收清单

| 检查项 | 通过证据 |
|---|---|
| 内容完整 | 可读文字逐项核对；精简有原文对照；不可辨关键项未被猜写 |
| 布局与逻辑 | 分区、对象对应、层级和箭头方向一致；修正有记录 |
| 无文字底稿 | SVG无text元素；人工核查无伪字、路径化残留文字 |
| 纯矢量 | 两份SVG无image元素或其他内嵌/外链位图，插图实际为矢量路径 |
| 回填可编辑 | 普通文字为SVG text和PPT原生文本框，公式处理单列 |
| 文字排版 | 无乱码、缺字、截断、溢出或遮挡；同层级字号一致；目视检查图文碰撞 |
| 黑白效果 | 最终预览为灰度，分类可由编号/边界/线型辨认，无残留分离底色 |
| 印刷尺寸 | 已知宽度按该尺寸检查；未知明确未验证最终缩印尺寸 |
| 素材完整 | 图标数量与清单对应，无缺边、断线和错误对象，来源可追踪 |
| 文件结构 | PPT ZIP/XML、媒体关系及manifest校验通过，SVG正常解析/渲染 |
| 最终实际打开 | 最终PPT打开、SVG导入及预览结果有应用名称和证据路径 |

检查JSON至少记录：源图尺寸、文字模式、简化范围、图标/文本框数量、各项 `passed/failed/not_run/not_applicable` 状态和证据路径、遗留问题、预览来源、最终尺寸及是否实际试印。仅当当前任务必需项通过才标 `complete`；项目待核或工具不可用如实标未完成/部分完成。

PowerPoint不可用时可做结构校验和其他渲染器预览，实际PowerPoint打开标 `not_run`，说明尚未验证该应用中的编辑效果。未试印时 `physical_print_test=false`。实际打开校验不得关闭用户已有文档或覆盖原图/旧成果。
